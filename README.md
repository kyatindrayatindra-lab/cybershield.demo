# 🛡️ CyberShield – Cybersecurity Website

A modern, responsive cybersecurity website built using HTML5 and CSS3.

## 🌐 Live Demo

[View CyberShield Website](https://kyatindrayatindra-lab.github.io/cybershield.demo/)

## 📌 About the Project

CyberShield is a frontend website project designed to showcase cybersecurity services and digital protection solutions through a professional, modern interface.

## ✨ Features

- Modern dark-themed design
- Responsive website layout
- Navigation menu
- Cybersecurity services section
- Threat protection section
- About section
- Contact section
- CSS hover effects

## 🛠️ Technologies Used

- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages

## 📂 Project Structure

```text
CyberShield/
├── index.html
├── style.css
└── README.md
```

## 🚀 How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/kyatindrayatindra-lab/cybershield.demo.git
```

2. Open the project folder.
3. Open `index.html` in your browser.

You can also use the Live Server extension in VS Code.

## 🎯 Project Objective

To develop practical frontend web development skills and understand how to design, build, version-control, and deploy a website.
